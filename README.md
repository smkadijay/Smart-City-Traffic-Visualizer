# Smart City Traffic Visualizer


## Track
Track C – Game / Graphics Industry / Freelancing

## Project Overview

UrbanFlow is a real-time smart city traffic visualization system developed using Python, PyOpenGL, and GLUT.

The project simulates a four-way road intersection where multiple vehicles move according to traffic signal rules. Vehicles stop and move based on signal states, creating a realistic traffic environment.

The system also includes day/night rendering, animated vehicles, traffic signals, environmental objects, and interactive controls.
